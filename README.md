**EcoSort** — программно-аппаратный комплекс для умного раздельного сбора отходов с автоматической классификацией через компьютерное зрение, честным весовым расчетом вознаграждений и эшелонированной системой кибербезопасности (**Anti-Fraud**).

Проект разработан студентами 1-го курса направления **«Информационная безопасность»** для конкурса *Eco-Startup & IT Challenge 2026*.

---

## 💡 Концепция и проблематика

Существующие урны раздельного сбора сталкиваются с двумя барьерами:
1. **Человеческий фактор:** людям сложно разбираться в маркировках, и в контейнеры попадает неподходящий мусор.
2. **Фальсификация и накрутка:** в системах с поощрительными баллами пользователи пытаются накручивать баланс повторной отправкой одних и тех же фото или снимками с экрана монитора.

**Решение EcoSort:**
* **Zero-Click маршрутизация:** пользователь просто отправляет фото предмета в Telegram-бот. Компьютерное зрение EcoSort за 1 секунду определяет тип сырья и автоматически подает сигнал на разблокировку нужного отсека бака.
* **Честный расчет по весу:** встроенные тензометрические датчики взвешивают сданный предмет. Начисление эко-баллов рассчитывается строго по реальному весу согласно официальным рыночным тарифам вторсырья.

## 🛡️ Архитектура кибербезопасности (4 рубежа Anti-Fraud)

Поскольку проект создавался будущими инженерами по информационной безопасности, ключевой фокус сделан на надежности и защите от злоупотреблений:

```
[Пользователь] 
      │ 
      ▼ (Фото отхода)
┌────────────────────────────────────────────────────────┐
│  Рубеж 1: Rate Limiting (Кулдаун 20 секунд)            │
└──────────────────────────┬─────────────────────────────┘
                           ▼
┌────────────────────────────────────────────────────────┐
│  Рубеж 2: SHA-256 Anti-Replay (Защита от дублей файлов)│
└──────────────────────────┬─────────────────────────────┘
                           ▼
┌────────────────────────────────────────────────────────┐
│  Рубеж 3: 64-bit dHash (Перцептивный поиск ракурсов)   │
└──────────────────────────┬─────────────────────────────┘
                           ▼
┌────────────────────────────────────────────────────────┐
│  Рубеж 4: AI Anti-Spoofing (Детект мониторов и стоков) │
└──────────────────────────┬─────────────────────────────┘
                           ▼
┌────────────────────────────────────────────────────────┐
│  Успех: Открытие створки + Фиксация веса по тарифу     │
└────────────────────────────────────────────────────────┘
```

1. **Rate Limiting (20 сек):** пресекает скриптовый фарм и флуд-атаки.
2. **SHA-256 Anti-Replay:** криптографическая сверка хеша файла в SQLite отсекает повторную отправку одинаковых картинок.
3. **Перцептивное хеширование (dHash 64-bit):** алгоритм нормализует градиенты яркости изображения и вычисляет расстояние Хэмминга ($dist \le 10$). Блокирует попытки перефотографировать один и тот же предмет под другим углом или при другом освещении.
4. **AI Anti-Spoofing:** нейросетевой фильтр артефактов экранов (пиксельная сетка, муар, блики) и стоковых картинок из интернета.

## 🚀 Быстрый запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/<ваш-username>/EcoSort.git
cd EcoSort
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Скопируйте пример файла конфигурации:
```bash
copy .env.example .env   # для Windows
# или cp .env.example .env для Linux/macOS
```
Укажите в `.env` ваши ключи:
```ini
TELEGRAM_BOT_TOKEN="ваш_токен_от_BotFather"
OPENAI_API_KEY="ваш_api_ключ_для_распознавания"
```

### 4. Запуск тестов безопасности
```bash
python test_system.py
```
*(Проверяет базу данных, dHash, поиск дубликатов и Rate Limit. 5/5 тестов должны пройти успешно).*

### 5. Запуск бота
```bash
python bot.py
```

```
└── .gitignore         # Защита от утечки секретов и тестовой БД
```
